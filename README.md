# Uber-Data-Analytics-Project

 Architected an end-to-end data engineering pipeline to extract, transform, and load (ETL) massive datasets into a centralized data warehouse.
 Developed Python scripts utilizing Pandas and NumPy to clean raw data, handle missing values, and execute complex transformations.
 Designed a robust star-schema data model (Fact and Dimension tables) to optimize SQL query performance and data retrieval speeds.
 Connected the cloud database directly to Power BI, building an interactive dashboard to track key business metrics and geospatial data.
